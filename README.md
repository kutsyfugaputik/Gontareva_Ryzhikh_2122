## Работа № 3. TodoList

### Описание проекта
`TodoList` — консольное приложение на C# для управления списком задач с помощью текстовых команд.

### Реализованные возможности
- Ввод имени, фамилии и года рождения пользователя при запуске.
- Непрерывная работа программы до ввода команды `exit`.
- Хранение задач в массиве `todos`, изначально рассчитанном на два элемента.
- Автоматическое увеличение массива в два раза при нехватке места.
- Копирование существующих задач в новый массив при расширении.

### Доступные команды

| Команда | Описание |
|:---|:---|
| `help` | Вывести список доступных команд |
| `profile` | Показать имя, фамилию и год рождения пользователя |
| `add "текст"` | Добавить задачу, указав её текст в кавычках |
| `view` | Вывести список всех задач |
| `exit` | Завершить работу программы |

### Пример работы

```text
> add "Купить молоко"
Задача добавлена

> view
1. Купить молоко

> exit
```
